# Life Planner

A personal planner: calendar (with US holidays), tasks, weekly plan, yearly goals, finances (bills, accounts, credit cards, savings goals), habits and journal, workouts (routines and per-set logging), calories (food search, nutrient guide, calorie calculator), cycle tracking, recipes and meal prep, and movie ratings.

Open it at https://rhcuai.github.io/Life-Planner/ and use your browser's "Add to Home Screen" or "Install" to use it like an app. It works offline. Entries are saved in the browser on each device.
